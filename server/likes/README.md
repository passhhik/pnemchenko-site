# Счётчик лайков

Сайт статический, своего сервера у него нет. Лайки считает маленькая облачная функция в Yandex Cloud: сайт шлёт ей «+1» или «−1» к проекту, админка забирает у неё числа. Посетителю его лайки видны и без счётчика — их помнит браузер.

**Что хранится:** адрес проекта и число. Ни адресов посетителей, ни cookie, ни меток — персональных данных нет.

**Сколько стоит:** для портфолио — ноль. У Cloud Functions и у бессерверной YDB есть бесплатный объём каждый месяц (миллион вызовов функции и миллион операций с базой), лайки до него не дотянут. Нужен платёжный аккаунт Yandex Cloud с картой — без него бесплатный объём не включается. Сверьте цены перед подключением: [функции](https://yandex.cloud/ru/docs/functions/pricing), [YDB](https://yandex.cloud/ru/docs/ydb/pricing/serverless).

## Как завести — 15 минут, один раз

Всё делается в консоли [console.yandex.cloud](https://console.yandex.cloud).

1. **База.** «Managed Service for YDB» → «Создать базу данных» → тип **Serverless**, имя `likes`. Когда база создана, на её странице скопируйте **Document API эндпоинт** (начинается с `https://docapi.serverless.yandexcloud.net/…`).
2. **Сервисный аккаунт.** «Сервисные аккаунты» → «Создать»: имя `likes`, роль **`ydb.editor`**. Откройте его → «Создать новый ключ» → **«Создать статический ключ доступа»**. Сохраните идентификатор ключа и секрет — секрет показывается один раз.
3. **Функция.** «Cloud Functions» → «Создать функцию», имя `likes`. Редактор → среда **Node.js 18** (или новее) → способ «Редактор кода». Создайте файлы `index.js` и `package.json` и вставьте в них содержимое одноимённых файлов из этой папки. Точка входа — `index.handler`. Таймаут — 5 секунд, память — 128 МБ.
4. **Переменные окружения** функции (там же, ниже):
   - `DOCAPI_ENDPOINT` — эндпоинт из шага 1;
   - `AWS_ACCESS_KEY_ID` — идентификатор ключа из шага 2;
   - `AWS_SECRET_ACCESS_KEY` — секрет из шага 2. Если хотите, чтобы секрет хранился в Lockbox, подставьте его оттуда — функция возьмёт его так же, из переменной.
   - `ALLOW_ORIGIN` — `https://pnemchenko.ru` (необязательно: без неё числа сможет прочитать любой сайт — секрета в них нет).
   
   «Сохранить изменения» — функция соберётся с зависимостью из `package.json`.
5. **Публичный доступ.** На странице функции включите «Публичная функция». Скопируйте её ссылку: `https://functions.yandexcloud.net/…`.
6. **Проверка.** Откройте ссылку в браузере — должно прийти `{"likes":{}}`. Таблица в базе создастся сама при первом обращении.
7. **Подключение к сайту.** Админка → «Настройки сайта» → «Лайки» → «Адрес счётчика» → вставьте ссылку из шага 5 → «Опубликовать». Через минуту-две лайки с сайта начнут считаться, а в админке рядом с проектами появятся числа (кнопка «Обновить числа» — свежие).

## Что надо знать

- **Бюджет с уведомлением.** В консоли: «Биллинг» → «Бюджеты» → бюджет, например, на 100 ₽ в месяц с письмом при 50% и 100%. Если счётчик начнут накручивать, вы узнаете раньше, чем придёт счёт.
- **Накрутить можно.** Один браузер ставит один лайк, но скрипт может слать запросы напрямую. Для портфолио это скорее теоретический риск; если случится — счётчик легко обнулить, удалив таблицу в базе (она создастся заново).
- **Обнулить один проект:** в консоли YDB откройте таблицу `likes` и удалите строку с адресом проекта.
- **Адрес проекта поменялся** — его лайки остаются под старым адресом.
- Политика безопасности страницы разрешает сайту обращаться к `functions.yandexcloud.net` и к API Gateway Yandex Cloud. Если счётчик будет жить где-то ещё, его адрес нужно дописать в строку `connect-src` в `index.html` и `admin/index.html`.
