Вход в админку

Забыли пароль — откройте в репозитории сайта на GitHub файл content/site.json и удалите блок «adminLock». Админка снова откроется без пароля.

Здесь добавляются и настраиваются кейсы

Подключите сайт — правки будут публиковаться прямо отсюда. Или работайте с папкой сайта на компьютере: админка читает и сохраняет файлы прямо в ней.

Без сайта и папки изменения скачиваются архивом: его нужно распаковать в папку сайта.

Подключить сайт

Админка будет отправлять правки в репозиторий сайта на GitHub — через минуту-две они появляются на сайте. Для этого нужен токен доступа. Он хранится только в этом браузере.

  1. Откройте на GitHub создание токена: Settings → Developer settings → Fine-grained tokens.
  2. Repository access: Only select repositories — выберите репозиторий сайта.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Нажмите Generate token, скопируйте токен и вставьте его сюда.

Сейчас админка открыта по незащищённому адресу (http), и токен по дороге могут перехватить. Подключить сайт можно по адресу с https или с этого компьютера: запустите start.command и откройте админку на localhost.

Пароль админки

Без него админка не откроется. Заработает после «Опубликовать» (с папкой — после «Сохранить»).

Не короче 8 знаков. Не берите пароль от GitHub или почты.
